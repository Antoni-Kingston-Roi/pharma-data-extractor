# Pharmaceutical Data Extractor

Automated drug data extraction using Python, Pandas, Selenium & Web Scraping.

## Tech Stack
- Python
- Selenium - for dynamic website scraping
- Pandas - for data cleaning
- BeautifulSoup

## How to Run
pip install -r requirements.txt
python main.py

## Output
- data/pharma_data_cleaned.csv
- data/pharma_data_cleaned.xlsx
